# Casey Room

Free, timed practice for chatbot-style online consulting cases: one case, one 35-minute clock (video answer included), no going back, and a worked solution for every question.

- 14 original cases, with question bubbles that turn green as you answer.
- Create your own cases: copy the prompt into any AI chat (ChatGPT, Claude, Gemini…) and paste the answer back. No API keys, nothing is sent from the page.
- Upload and download cases as `.json`. Attempts and your own cases are kept in your browser's `localStorage` only.

Everything is in `index.html` (cases live in its `<script id="case-data">` JSON block) plus the self-hosted fonts in `fonts/`. Design system adapted from [Assessmint](https://github.com/jopecl/assessmint), in navy.

Personal practice tool. Not affiliated with or endorsed by any consulting firm or its assessment provider; all cases are original.
