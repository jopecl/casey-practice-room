# Casey Practice Room

Timed practice simulator for online chatbot-style consulting case assessments: one case, a single 35-minute clock (video answer included), no going back, worked solutions at the end. 14 original cases.

Live: GitHub Pages (see the repository's *About* link).

Everything runs in the browser in a single `index.html`; attempts are saved in your browser's local storage only. Cases live in the `<script id="case-data">` JSON block.

Personal practice tool. Not affiliated with or endorsed by BCG or its assessment provider; all cases are original.
